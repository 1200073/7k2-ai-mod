## ★ 需要帮忙的三件事

### 🥇 中立巢穴主动出击（最想要）

**现状**：能让兵"出来并移动"，但**不会攻击任何人**。

已经打通的部分：

| 项 | 状态 |
|---|---|
| 找到出巢函数 `FirmCamp::patrol()` = `0x00478160` | ✅ |
| 中立巢穴可安全调用（它只读 `player_recno`） | ✅ 零崩溃 |
| 兵真的能出来（15/15、16/16，零丢失） | ✅ 实测 |
| `unit_group.assign()` 能让它们走动 | ✅ 实测 |

卡住的部分：

| 尝试 | 结果 |
|---|---|
| `unit_group.attack(objRecno, COMMAND_AI)` | ❌ 静默无反应 |
| 逐单位 `Unit::attack(objRecno, ...)` | ❌ 静默无反应 |

**根因**（已确认）：

```c
Unit::attack() → set_attack()
                  ├─ if( !can_attack() )                  return 0;
                  └─ if( !validate_attack_target() )      return 0;
```

中立巢穴 `nation_recno == 0` ⇒ 没有 `Nation` 对象 ⇒ 没有外交关系 ⇒ 没有"敌对"状态 ⇒ 关卡二必然拒绝。

**求思路**：

- 有没有办法在**不给 Nation** 的前提下让中立单位获得"敌对"状态？
- 伪造敌对关系表？
- hook `validate_attack_target` 的返回值？
- 还是别的路？

**详见 [`05-dead-ends.md`](05-dead-ends.md) 死路 1。**
